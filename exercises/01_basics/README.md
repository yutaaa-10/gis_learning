# 演習01 東京・横浜・藤沢を可視化する

地図上の位置を、都市名と座標を持つ3つのレコードとして表現します。代表点は各市の市役所など、自分で同じ基準を決めて選び、座標の出典を控えます。

1. このフォルダに `plot_cities.py` を作り、都市名・緯度・経度を3都市分記録する。
2. どの値を横軸と縦軸に渡すか考え、Matplotlibの散布図に3つの点を描く。
3. 軸ラベルと都市名を付け、元の座標と点の並びを見比べる。

最初のヒント。1都市を1つの辞書、3都市を辞書のリストにすると、各都市の名前と座標をまとめて扱えます。辞書のキーには `name`、`latitude`、`longitude` を使えます。

描画できたら、座標の出典と点の並びを確認した方法を、このページに短く記録します。
