# QGIS基礎学習

## 学習目的

QGISを用いた地理データの読み込み、可視化、
抽出、座標変換、保存の基本操作を理解する。

## 使用データ

- 提供元：国土交通省 国土数値情報
- データ：行政区域（N03）
- 対象地域：神奈川県
- 基準日：2026年1月1日
- ファイル形式：GeoJSON
- CRS：EPSG:6668（JGD2011）
- URL：https://nlftp.mlit.go.jp/ksj/

## 学習内容

### XYZタイル

表示範囲やズームレベルに応じて、
必要な地図画像をサーバーから取得する仕組み。

### レイヤー

異なる地理データを独立して管理し、
同じ空間上に重ね合わせる仕組み。

### GeoJSON

地理データをJSON形式で保持するファイル形式。

- FeatureCollection：地物の集合
- Feature：個々の地物
- Geometry：図形情報
- Properties：属性情報

### オンザフライ座標変換

異なるCRSを持つ地理データを、
元データを変更せずに表示時に座標変換する仕組み。

### 属性テーブル

地物に紐づく属性情報を表形式で管理する。

### 条件抽出

属性情報を利用して、特定の地物を選択する。

今回使用した条件式：

"N03_004" = '藤沢市'

### エクスポート

選択した地物を別のファイルとして保存する。

今回は藤沢市の行政区域を抽出し、
EPSG:4326に変換してGeoJSONとして保存した。

## データ処理の流れ

1. オープンデータの取得
2. QGISへの読み込み
3. 地理データの可視化
4. 属性情報による抽出
5. 座標変換
6. 加工データの保存

## データの配置

- data/raw/N03-20260101_14_GML/
- data/processed/fujisawa.geojson
- qgis/kanagawa_basics.qgz

元データと加工データはGitの管理対象外とする。
QGISプロジェクトを再現するには、データの取得と配置が必要。

## 学んだこと

GISは単に地図を表示する技術ではなく、
位置情報を共通の軸として異なるデータを組み合わせ、
加工・分析する技術である。

QGISで手動で行った処理は、
GeoPandasを利用することでプログラムによる自動化が可能。
