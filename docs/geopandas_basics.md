4. GeoPandasとは

GeoPandasは、Pandasを拡張して地理データを扱えるようにしたPythonライブラリである。

通常のDataFrameに図形情報と座標参照系を扱う機能が追加されている。

GeoDataFrame

GeoDataFrameは以下の情報を管理するデータ構造である。

* 属性情報：名称、行政区域コードなど
* Geometry：Point、LineString、Polygon、MultiPolygonなど
* CRS：座標参照系

1行が1つの地物（Feature）に対応する。

1つの行政区域が複数の地物によって構成される場合もある。

5. 実装内容

5.1 データの読み込み

gpd.read_file() を使用してGeoJSONをGeoDataFrameに変換した。

内部ではPyogrioやGDAL/OGRなどのライブラリが利用されている。

5.2 属性検索

Boolean Indexingを利用して、神奈川県の行政区域データから藤沢市を抽出した。

fujisawa = gdf[gdf["N03_004"] == "藤沢市"].copy()

全地物に対して条件を評価し、一致する地物のみを取得する。

5.3 座標変換

to_crs() を使用して、目的に応じた座標参照系への変換を行った。

EPSG	座標参照系	単位	用途
6668	JGD2011	度	元データ
4326	WGS84	度	データ保存・可視化
3857	Web Mercator	m	Web地図
6677	JGD2011 平面直角座標系IX	m	距離・面積計算

to_crs() は座標値を変換する。

set_crs() は座標値を変更せず、座標参照系を設定する。

距離や面積を計算する場合は、対象地域に適した投影座標系を使用することが重要である。

5.4 データの保存

to_file() を使用して、抽出・座標変換した藤沢市のデータをGeoJSONとして保存した。

fujisawa_wgs84.to_file(
    "data/processed/fujisawa_python.geojson",
    driver="GeoJSON"
)

5.5 可視化

GeoPandasの plot() とMatplotlibを使用して地理データを可視化した。

同じAxesに複数の地理データを描画することで、QGISのレイヤーの重ね合わせを再現した。

* 神奈川県全体の行政区域
* 藤沢市の行政区域
* 藤沢駅・辻堂駅の位置
* 各駅から半径500mの範囲

5.6 面積計算

EPSG:6677に座標変換し、各地物の面積を計算した。

fujisawa_projected = fujisawa.to_crs("EPSG:6677")
area_km2 = fujisawa_projected.area.sum() / 1_000_000

面積計算では、多角形の頂点座標を利用した幾何学的演算が行われる。

地物同士が重複する場合は、面積の二重計上に注意する必要がある。

5.7 距離計算

Shapelyの Point() を使用して駅の位置情報を生成した。

平面直角座標系に変換した後、distance() を使用して2地点間の直線距離を計算する処理を実装した。

平面上の2点間の距離はユークリッド距離によって求められる。

5.8 バッファー生成

buffer() を使用して、駅から半径500mの領域を生成した。

station_buffers["geometry"] = (
    stations_projected.geometry.buffer(500)
)

PointからPolygonを生成することで、特定地点から一定距離以内の領域を表現できる。

5.9 図形の集合演算

地理データに対して集合論を適用することで、複数の図形の空間的な関係を分析できる。

メソッド	役割
union_all()	複数の図形を統合する
intersection()	重複する領域を取得する
difference()	一方の図形から重複領域を除外する
symmetric_difference()	重複しない領域を取得する
intersects()	図形が交差しているか判定する
within()	図形が別の図形の内部にあるか判定する

7. QGISとPythonの違い

比較項目	QGIS	Python（GeoPandas）
インターフェース	GUI	API・コード
操作性	直感的	プログラムの記述が必要
可視化	地図専用の機能が豊富	自由に設計可能
データ探索	目視による確認が容易	条件を定義して探索
自動化	モデルやスクリプトで対応	柔軟に設計可能
外部連携	プラグインやAPI	AI・DB・Web APIなど
バージョン管理	比較的難しい	Gitで管理しやすい

QGISは地理データの探索・可視化・検証に適している。

Pythonは独自の分析処理の実装・自動化・システム化に適している。

両者は対立するものではなく、組み合わせて利用することで効率的な地理データ分析が可能になる。

また、QGISもPyQGISを利用することで、Pythonによる操作や拡張が可能である。

8. コンピュータサイエンスとの関連

データ構造

GeoDataFrameによって属性情報と図形情報を関連付けて管理する。

アルゴリズム

属性検索では、全地物に対して条件を評価する。

行数をNとした場合、条件判定の時間計算量はO(N)となる。

計算幾何学（Computational Geometry）

座標や図形を対象とした数学的・アルゴリズム的な処理を扱う分野である。

GISでは以下のような処理に利用される。

* 多角形の面積計算
* 2地点間の距離計算
* 図形の交差判定
* 図形の包含判定
* 図形の集合演算

抽象化

GeoPandasは、GDAL、GEOS、PROJなどの基盤技術を利用し、複雑な地理データ処理をPythonのメソッドとして抽象化している。

データエンジニアリング

今回の実装はETLの基本的な構成に対応している。

* Extract：地理データの読み込み
* Transform：条件抽出・座標変換・加工
* Load：加工データの保存

処理をプログラム化することで、再現性の確保や繰り返し処理の自動化が可能になる。
